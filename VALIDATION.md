# Проверка Cowabunga Jellyfin Companion

## Версия 1.0.4

259 тестов прошли. Проверены разрешение поиска без пути при включённом модуле (без разрешения записи без пути), запрет поиска при выключенном модуле и по известному исключённому пути, замена английского описания и слогана русскими, повторное применение без изменений, отсутствие перевода, выключенные поля и блокировки. По исходникам Jellyfin 12 подтверждены передача SearchInfo без заполнения Path и приоритет выбранного провайдера при ручной идентификации. Конкретные фильмы пользователя на его сервере не проверялись.

## Версия 1.0.3

255 тестов прошли. Регрессия пустого списка Custom Artwork в режиме MediaFolder покрыта для Movie, Series и Season: индекс с постером и логотипом возвращает оба варианта без скачивания оригиналов и записи файлов; исключение медиатеки по-прежнему даёт пустой результат. Проверки фоновой записи, защиты локальных файлов и одинаковых хешей остаются в наборе. Реальный сервер пользователя не проверялся. Эта версия заменяет прежнее ограничение из теста 1.0.2, запрещавшее выдачу кандидатов в MediaFolder.

## Версия 1.0.2

253 теста прошли. Добавлены проверки обнаружения провайдеров на тестовых объектах Jellyfin, запрета загрузок вне выбранных медиатек и при выключенном модуле, отсутствия параллельной удалённой загрузки в режиме хранения рядом с видео. На настоящем Jellyfin 12 API `Libraries/AvailableOptions` возвращает для фильмов Cowabunga Companion Metadata, Custom Artwork и Language Artwork. Проверка JavaScript страниц пройдена.

## Версия 1.0.1

251 тест прошёл в Release под .NET 10 / Jellyfin 12; проверка JavaScript всех четырёх страниц прошла. Регрессия языка коллекций воспроизводится через штатный `OrderByLanguageDescending` Jellyfin: без фильтра русский язык метаданных поднимает русский постер; после фильтра выбранный язык сохраняется. Проверены английский и русский приоритеты, отдельный резервный язык логотипов и отключение роли. Живая коллекция пользователя не проверялась.

## Проверки версии 1.0.0

Дата: 9 сентября 2026.

## Выполнено локально

- Логотип Cowabunga включён в установочный пакет и страницу настроек. На тестовом Jellyfin 12 проверены отображение шапки в браузере и выдача исходного JPEG через штатный API изображений плагинов (байты совпадают с оригиналом).

- Release-сборка под .NET 10 с Jellyfin.Controller / Jellyfin.Model 12.0.0. Без ошибок и предупреждений компилятора.
- 247 модульных и регрессионных тестов прошли. Отдельные устаревшие тесты удалённых менеджеров заменены тестами общей очереди и общего управления медиатеками.
- Проверка синтаксиса JavaScript, UTF-8 и GUID всех четырёх страниц настроек.
- Настоящий сервер из официального образа `jellyfin/jellyfin:12.0`, digest `sha256:baba630419915985442f315f08b0cf46d9f4c8a0cc4bd38e94a6d35751dd5ef5`, в изолированном Docker-контейнере, доступном только через localhost.
- Загрузка единственного плагина с именем Cowabunga Jellyfin Companion и версией 1.0.0.0.
- Отказ в доступе без авторизации для API Companion, Smart Resolver и Choose your Meta.
- Сканирование тестовых видео: фильм распознан по имени `Moonraker (1979).mkv`, вложенный сериал привязан к внутренней папке, эпизод найден.
- Фильм `2012 (2009)` с двумя файлами версий 1080p/2160p после реального сканирования представлен одной карточкой с двумя источниками. Числовое название сохранено.
- Исключённая медиатека не появляется в истории действий Resolver. Выключение Resolver без перезапуска прекращает его действия при повторном сканировании.
- Веб-интерфейс Jellyfin: загрузка главной страницы, восстановление выбранных медиатек, сохранение настроек, переходы на страницы Resolver, Metadata и Artwork, обнаружение встроенного ключа TMDB.

## Отдельные сценарии автоматических тестов

- Все восемь сочетаний трёх модулей и главный выключатель.
- ID медиатеки после переименования, вложенные и одинаковые корни, границы пути, коллекции с отдельной областью действия.
- Повторный вход в проверку области действия при построении корня Jellyfin без рекурсии.
- Очередь изображений: объединение дубликатов, сохранение между перезапусками, ограниченный рост интервала повторов.
- Отключение модуля/медиатеки после постановки в очередь и после начала загрузки.
- Приоритет Custom Artwork над языковым подбором; ошибка облака не запускает замену из другого источника.
- Сохранение текущего файла при ошибке скачивания; защита ручной замены по хешу.
- Учёт загрузок штатным конвейером Jellyfin; проверка SHA-256 кастомного файла; перенос прежнего учёта изображений без перезаписи ручных замен.
- XML-конфигурация с русским текстом и независимыми параметрами модулей; импорт старого выключателя Resolver не выключает весь Companion.

## Границы проверки

Рабочий сервер и реальные медиатеки пользователя не изменялись. Сетевые сценарии выбора/записи изображений проверены детерминированными ответами HTTP; облачный индекс дополнительно успешно читался в тестовом сервере, но полное обновление пользовательской коллекции через внешние TMDB/Fanart/Wikidata не проводилось. Полная миграция с установленными тремя плагинами на рабочей базе не выполнялась.

Тесты выполнялись в Linux-контейнере на Windows-хосте. CI для Windows, Linux и macOS добавлен, но удалённые CI-задания ещё не запускались. Поддержка будущих версий Jellyfin требует отдельной проверки.
