Custom Artwork

Скачивается только файл ревизии размером в несколько десятков байт. Полный индекс загружается лишь после изменения ревизии.
Во втором режиме Jellyfin должен иметь право записи в папки медиатеки. По умолчанию существующие постеры и логотипы, созданные не этим плагином, не перезаписываются. Для коллекций используется служебная папка коллекции внутри данных Jellyfin. При хранении рядом с видео изображения записывает фоновая задача Companion; наличие провайдера в списке Jellyfin само по себе не включает модуль для медиатеки.
Разрешает плагину заменять используемые Jellyfin файлы poster, folder, cover, default, clearlogo и logo в папках медиатеки, даже если они были созданы не этим плагином. Без галочки такие файлы сохраняются.
