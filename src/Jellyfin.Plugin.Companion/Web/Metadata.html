Коллекции


Постеры коллекций загружаются из TMDB, логотипы — через официальный плагин Fanart.
Российский фильм определяется по стране производства RU; если страна не заполнена — по исходному языку ru. В каждой паре второй язык используется как резерв. Для каждого поля английское значение сохраняется, если русский вариант не найден. Локальные изображения имеют приоритет, фоны плагин не изменяет. Чтобы заменить уже сохранённые картинки, обновите фильм с включённой заменой изображений.

Автоматическая настройка библиотек

Применяет сохранённый выбор модулей и медиатек с главной страницы Companion. Не включает выключенные модули и не расширяет список выбранных медиатек. Включённые источники изображений Companion ставятся первыми: Custom Artwork, затем языковой подбор Choose your Meta. Остальные загрузчики и их взаимный порядок сохраняются. Для коллекций используются отдельные разрешения с главной страницы.
